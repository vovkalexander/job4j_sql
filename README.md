
# Job4j_sql


Данный раздел посвещен  работе с реляционными базами данных и языком SQL на примере СУБД PostgreSQL. 
Раздел посвящен базовым и прикладным аспектам работа с базой данных: от устройства таблиц и связей между ними 
до написания запросов, проектирования схемы и решения практических задач.

Так же будут рассмотрины процесы связанным с эксплуатацией и производительностью PostgreSQL: транзакциям, 
базовым вопросам конкурентного доступа, индексам и их влиянию на выполнение запросов.
